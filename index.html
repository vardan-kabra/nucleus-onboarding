Nucleus · Setup

Developer Setup Guideડેવલપર સેટઅપ માર્ગદર્શિકા

From a blank Windows 11 PC to the Nucleus app running on your machine — step by step.ખાલી Windows 11 PC થી લઈને Nucleus એપ્લિકેશન તમારા કમ્પ્યુટર પર ચાલુ થાય ત્યાં સુધી — પગલું-દર-પગલું.

How this works: two things you install by hand, then one script installs everything, and one script sets up the project. About 30 minutes, mostly hands-off. આ કેવી રીતે કામ કરે છે: બે વસ્તુ તમે જાતે ઇન્સ્ટોલ કરો, પછી એક સ્ક્રિપ્ટ બધું ઇન્સ્ટોલ કરે છે, અને એક સ્ક્રિપ્ટ પ્રોજેક્ટ સેટઅપ કરે છે. લગભગ 30 મિનિટ, મોટાભાગનું ઓટોમેટિક.

What you're setting upતમે શું સેટઅપ કરી રહ્યા છો

Nucleus is the ERP we are building in-house for the school — admissions, HR, results, fees, transport. Alongside it is a second repository of about two dozen smaller apps, each proving one capability on realistic data before it is built into the main system.Nucleus એ શાળા માટે આપણે જાતે બનાવી રહ્યા છીએ તે ERP છે — એડમિશન, HR, પરિણામ, ફી, ટ્રાન્સપોર્ટ. તેની સાથે બીજી એક રિપોઝીટરી છે જેમાં આશરે બે ડઝન નાની એપ્લિકેશન છે; દરેક એપ્લિકેશન કોઈ એક ક્ષમતા વાસ્તવિક ડેટા પર સાબિત કરે છે, તે મુખ્ય સિસ્ટમમાં ઉમેરાય તે પહેલાં.

It is all one stack, so learning it once covers everything: Next.js and TypeScript for the apps, Postgres for the data, Prisma in between.બધું એક જ સ્ટૅક છે, એટલે એક વાર શીખ્યા પછી બધે કામ લાગે છે: એપ્લિકેશન માટે Next.js અને TypeScript, ડેટા માટે Postgres, અને વચ્ચે Prisma.

You cannot break anything. Everything here runs only on your own machine. The live systems staff use are deployed elsewhere and are not touched by any of this. તમે કંઈ બગાડી શકતા નથી. અહીંનું બધું ફક્ત તમારા પોતાના કમ્પ્યુટર પર ચાલે છે. સ્ટાફ જે લાઇવ સિસ્ટમ વાપરે છે તે બીજે ડિપ્લોય થયેલી છે અને આનાથી તેને કંઈ થતું નથી.

0Accept your GitHub invitationsતમારા GitHub આમંત્રણો સ્વીકારો

You have been invited to the private repositories. Open github.com/notifications, or the email from GitHub, and accept every one.તમને ખાનગી રિપોઝીટરીઓમાં આમંત્રણ મોકલવામાં આવ્યું છે. github.com/notifications ખોલો, અથવા GitHub તરફથી આવેલો ઈમેલ જુઓ, અને દરેક આમંત્રણ સ્વીકારો.

Do this first, and don't leave it. GitHub invitations expire after 7 days, and nobody is told when they lapse. આ સૌથી પહેલાં કરો, મુલતવી ન રાખો. GitHub આમંત્રણ 7 દિવસ પછી સમાપ્ત થઈ જાય છે, અને સમાપ્ત થાય ત્યારે કોઈને જાણ થતી નથી.

Every repository here is private. Until the invitations are accepted, the setup script cannot download a single line of code.અહીંની દરેક રિપોઝીટરી ખાનગી છે. આમંત્રણ સ્વીકારાય નહીં ત્યાં સુધી સેટઅપ સ્ક્રિપ્ટ કોડની એક લીટી પણ ડાઉનલોડ કરી શકતી નથી.

1Install two things by handબે વસ્તુઓ જાતે ઇન્સ્ટોલ કરો

Everything else is automated. Start with these:બાકી બધું ઓટોમેટિક છે. આનાથી શરૂ કરો:

  • Git for Windows — version control, and the shell the tools use.વર્ઝન કંટ્રોલ, અને શેલ જે બધા ટૂલ વાપરે છે.
  • Claude Code — your main tool here; it can run the whole setup for you.તમારું મુખ્ય સાધન; તે આખું સેટઅપ તમારા માટે ચલાવી શકે છે.
If PowerShell refuses to run scripts, run this once: જો PowerShell સ્ક્રિપ્ટ ચલાવવાની ના પાડે, તો એક વાર આ ચલાવો:
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

2Install the toolchainટૂલચેઇન (સાધનો) ઇન્સ્ટોલ કરો

In PowerShell, run the bootstrap script and approve the admin (UAC) prompt:PowerShell માં bootstrap સ્ક્રિપ્ટ ચલાવો અને એડમિન (UAC) પ્રોમ્પ્ટને મંજૂરી આપો:

.\bootstrap.ps1

It installs, automatically:તે આપમેળે આ ઇન્સ્ટોલ કરે છે:

Node.jsPythonDocker + WSL2VS CodeGitHub CLIPowerShell 7Windows TerminalDBeaverMongoDB CompassRailway CLI

Databases run inside Docker containers — nothing is installed on Windows directly.ડેટાબેઝ Docker કન્ટેનર અંદર ચાલે છે — Windows પર સીધું કંઈ ઇન્સ્ટોલ થતું નથી.

Restart your PC when it finishes. Docker and WSL need the reboot before they will start. પૂરું થાય પછી PC રીસ્ટાર્ટ કરો. Docker અને WSL શરૂ થાય તે પહેલાં રીસ્ટાર્ટ જરૂરી છે.

3Sign in to GitHub & DockerGitHub અને Docker માં સાઇન ઇન કરો

These two are interactive — do them yourself:આ બે વસ્તુઓ જાતે કરવાની છે:

gh auth login

Choose: GitHub.com → HTTPS → Login with a web browser, copy the one-time code, and authorize in the browser.પસંદ કરો: GitHub.com → HTTPS → બ્રાઉઝર દ્વારા લોગિન, વન-ટાઇમ કોડ કૉપિ કરો, અને બ્રાઉઝરમાં મંજૂરી આપો.

Then open Docker Desktop once and accept its licence agreement.પછી Docker Desktop એક વાર ખોલો અને તેની લાઇસન્સ શરત સ્વીકારો.

GitHub login must happen before installing — Nucleus depends on a private repository. Skip it and the install fails naming the design system, not the missing login, which sends people hunting in the wrong place.ઇન્સ્ટોલ કરતાં પહેલાં GitHub લોગિન જરૂરી છે — Nucleus એક ખાનગી રિપોઝીટરી પર આધાર રાખે છે. આ છોડી દો તો ઇન્સ્ટોલ નિષ્ફળ થાય છે અને ભૂલમાં ડિઝાઇન સિસ્ટમનું નામ આવે છે, ખૂટતા લોગિનનું નહીં — એટલે લોકો ખોટી જગ્યાએ શોધવા લાગે છે.

4Set up the projectપ્રોજેક્ટ સેટઅપ કરો

Clone Nucleus, then run its setup script:Nucleus ક્લોન કરો, પછી તેની સેટઅપ સ્ક્રિપ્ટ ચલાવો:

gh repo clone vardan-kabra/nucleus C:\dev\nucleus cd C:\dev\nucleus .\scripts\dev-setup.ps1

This installs all dependencies, starts the database (Postgres on port 5440), runs the migrations and tests, and clones the related repos — all automatically.આ બધી ડિપેન્ડન્સી ઇન્સ્ટોલ કરે છે, ડેટાબેઝ (પોર્ટ 5440 પર Postgres) શરૂ કરે છે, migration અને ટેસ્ટ ચલાવે છે, અને સંબંધિત રિપો ક્લોન કરે છે — બધું આપમેળે.

Clone, don't download a ZIP. Downloading a ZIP is fine for this setup folder, but the code repositories must be cloned — that is what lets Git track your changes and lets you send work back. The command above does it for you. ZIP ડાઉનલોડ નહીં, clone કરો. આ સેટઅપ ફોલ્ડર માટે ZIP ડાઉનલોડ કરવું ઠીક છે, પણ કોડની રિપોઝીટરીઓ clone કરવી જ પડે — તેનાથી જ Git તમારા ફેરફારો ટ્રૅક કરે છે અને તમે કામ પાછું મોકલી શકો છો. ઉપરનો આદેશ એ કામ તમારા માટે કરે છે.

Use exactly C:\dev\nucleus. Several tools store settings against the full folder path, so a different location works but breaks small things confusingly later.બરાબર C:\dev\nucleus જ વાપરો. કેટલાંક ટૂલ પૂરા ફોલ્ડર પાથ સામે સેટિંગ સાચવે છે, એટલે બીજી જગ્યાએ ચાલશે તો ખરું, પણ પછી નાની નાની વસ્તુઓ ગૂંચવણભરી રીતે બગડે છે.

5Run itએપ્લિકેશન ચલાવો

npm run dev
Open http://localhost:3200 — you should see the Nucleus operator console. You're set up! 🎉 http://localhost:3200 ખોલો — તમને Nucleus ઓપરેટર કન્સોલ દેખાવું જોઈએ. સેટઅપ પૂરું! 🎉

+If you also need the smaller appsજો તમને નાની એપ્લિકેશન પણ જોઈએ

Step 4 sets up the main Nucleus system. The two dozen smaller apps live in nucleus-prototypes, each with its own database and its own port.પગલું 4 મુખ્ય Nucleus સિસ્ટમ સેટઅપ કરે છે. બે ડઝન નાની એપ્લિકેશન nucleus-prototypes માં છે, દરેકનું પોતાનું ડેટાબેઝ અને પોતાનો પોર્ટ છે.

You don't have to work that out by hand. Open Claude Code in an empty folder and paste in NUCLEUS-ESTATE-SETUP.md from this same folder — it runs every step, stops wherever you need to sign in, and explains as it goes.એ જાતે શોધવાની જરૂર નથી. ખાલી ફોલ્ડરમાં Claude Code ખોલો અને આ જ ફોલ્ડરમાંથી NUCLEUS-ESTATE-SETUP.md પેસ્ટ કરો — તે દરેક પગલું ચલાવે છે, જ્યાં સાઇન ઇન કરવાનું હોય ત્યાં અટકે છે, અને સાથે સાથે સમજાવે છે.

?If something goes wrongકંઈક ખોટું થાય તો

  • npm install finished but Prisma or the tests break → run npm approve-scripts --all.npm install પૂરું થયું પણ Prisma કે ટેસ્ટ કામ ન કરે → npm approve-scripts --all ચલાવો.
  • Install fails on @fountainhead/design-system → you're not logged into GitHub; run gh auth login first.@fountainhead/design-system પર ઇન્સ્ટોલ નિષ્ફળ → તમે GitHub માં લોગિન નથી; પહેલા gh auth login કરો.
  • Docker or WSL won't start → make sure you restarted the PC after Step 2. Check with wsl --status.Docker કે WSL શરૂ ન થાય → ખાતરી કરો કે Step 2 પછી PC રીસ્ટાર્ટ કર્યું છે. wsl --status થી તપાસો.
  • A database test times out the first time → run it again; it passes the second time (cold start).પહેલી વાર ડેટાબેઝ ટેસ્ટ ટાઇમઆઉટ થાય → ફરી ચલાવો; બીજી વાર પાસ થશે (કોલ્ડ સ્ટાર્ટ).
  • Ports to remember: Postgres = 5440, the app = 3200.યાદ રાખવાના પોર્ટ: Postgres = 5440, એપ્લિકેશન = 3200.
Stuck on any step? Open Claude Code and paste the setup prompt from the README — it runs every step and explains as it goes, in plain language. કોઈ પગલામાં અટકી ગયા? Claude Code ખોલો અને README માંથી સેટઅપ પ્રોમ્પ્ટ પેસ્ટ કરો — તે દરેક પગલું ચલાવે છે અને સરળ ભાષામાં સમજાવે છે.
